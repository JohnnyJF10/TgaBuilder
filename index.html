TgaBuilder

Texture Panel Building Tool for TRLE

A modern re-creation of the classic TBuilder tool to build texture panels for TRLE with new features like batch loading, transitions making, on-the-fly non destructive image modificationsand more. Built in .NET with WPF (Windows) and Avalonia UI (cross-platform).

Download Latest View on GitHub

Features

Texture Panel Building

Pan, zoom, and place textures with extended dimensioning — up to 128 pages height and 16 pages width.

Undo / Redo

Full undo/redo history for all operations.

Batch Loader

Create texture panels from multiple single texture files at once with automatic layout.

Smooth Transitions

Generate smooth transition tiles with configurable hardness, widening, shift, and pivot controls.

Brick Transitions

Advanced brick segmentation with 6 algorithms (Felzenszwalb, SLIC, Quickshift, Watershed, Brick Fit, Grid Fit).

Modifications

Non-destructive adjustments — brightness, contrast, hue, saturation, color overlay with OKLab blending.

Multi-Format Support

Better support for 128×128 or 256×256 px texture sets with imported texture repacking.

Cross-Platform

WPF for Windows (.NET 6/8) and Avalonia UI for Linux/macOS (preview).

Quick Start

1

Download

Get the latest release from GitHub Releases

2

Extract & Run

TgaBuilder.exe (Windows) or dotnet TgaBuilderAvaloniaUi.dll (Linux)

3

Open Panels

Source panel Ctrl+E and destination panel Ctrl+D

4

Build & Save

Pick tiles from source, place on destination, save with Ctrl+S
